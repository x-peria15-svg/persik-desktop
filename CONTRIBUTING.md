# Участие в проекте

Спасибо за интерес к Персику. Для исправления ошибки укажите версию приложения, Windows и шаги воспроизведения. Не прикладывайте личные данные и содержимое папок пользователя. Сохранение можно приложить только после самостоятельного удаления личных сведений из имени и журнала.

Перед предложением изменения выполните на Windows:

```powershell
./build.ps1 -Test
```

Для изменений интерфейса проверьте светлую/тёмную тему и компактный режим. Новые игровые награды должны иметь ограничения от повторного начисления. Новые предметы обязаны сохраняться и корректно сниматься.

Соблюдайте `.editorconfig`. Не добавляйте зависимости, сетевые запросы и внешние ассеты без обсуждения. Вклад распространяется под лицензией проекта Apache-2.0. Сообщения об уязвимостях — по инструкции в `SECURITY.md`.
