## Персик 3.0.0

Готовый питомец для Windows: 4 комнаты, самостоятельные прогулки, 6 мини-игр, 18 товаров, шляпы, расцветки, бантик и уход под душем.

**Скачайте `Persik-3.0.0-Windows.zip`, распакуйте и запустите `Persik/PixelCat.exe`.**

- Windows 10/11 и .NET Framework 4.8.
- Без установки, регистрации, сетевых запросов и реальных платежей.
- Старые сохранения подхватываются автоматически; перед обновлением закройте прежнюю версию.
- Файл не подписан сертификатом; контрольные суммы — в `SHA256SUMS.txt`.
- `Source code` содержит исходники, а не готовую программу.

Сборка и автоматические проверки выполняются GitHub Actions. Подробная инструкция — в README репозитория и внутри ZIP.
