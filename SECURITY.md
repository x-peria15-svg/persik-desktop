# Безопасность

Поддерживается последняя опубликованная версия. Приложение работает локально без сетевых запросов и повышенных прав; сохранения не шифруются и находятся в профиле пользователя.

Для сообщения об уязвимости используйте **Security → Advisories → Report a vulnerability** в этом репозитории. Не публикуйте токены, личные файлы и подробности эксплуатации в общедоступных Issues. Если приватная форма недоступна, создайте краткий Issue с просьбой о приватном канале без технических подробностей.

Релизы не подписаны сертификатом. Скачивайте готовую программу только из Releases этого репозитория и сравнивайте SHA-256 с опубликованным `SHA256SUMS.txt`. Контрольная сумма проверяет целостность файла, но не заменяет цифровую подпись.
